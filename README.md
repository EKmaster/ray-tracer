# Ray tracer

A simple raytracer (path tracer), coded in modern C++, following various tutorials:

- [*Introduction to Raytracing: A Simple Method for Creating 3D Images*](https://scratchapixel.com/lessons/3d-basic-rendering/introduction-to-ray-tracing/how-does-it-work.html)
- [*The Ray Tracing in One Weekend* series](https://raytracing.github.io/)
